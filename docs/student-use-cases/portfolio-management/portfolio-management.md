# Student Use Case 2: Manage Portfolio

## Actor

Student

## Goal

Allow students to create, update, and manage their career portfolio on CareerUp.

## Preconditions

- Student has access to their CareerUp account.
- Student is viewing their portfolio.

## Main Flow

1. Student selects "My Portfolio."
2. CareerUp displays the student's existing portfolio.
3. Student selects "Add Project" or chooses an existing project to edit.
4. Student enters or updates project information.
5. Student saves the changes.
6. CareerUp validates the information.
7. CareerUp updates the student's portfolio.
8. CareerUp displays the updated portfolio.

## Student Actions

- View portfolio
- Add a project
- Edit project information
- Remove a project
- Add project descriptions
- Add skills associated with a project
- Save portfolio changes

## Screen Components

- Portfolio header
- Student profile information
- Projects section
- Add Project button
- Edit Project button
- Project title
- Project description
- Skills
- Save button
- Delete/Remove button

## Alternative Flow

If required project information is missing, CareerUp displays an error message and asks the student to complete the missing information before saving.

## Postcondition

The student's portfolio contains the updated project information.

## Screens Needed

1. My Portfolio
2. Add/Edit Project
